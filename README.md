# Chandru Chandraan — Portfolio

Interactive 3D Game Developer & Simulation Engineer portfolio built with React, Three.js / React Three Fiber, GSAP, Tailwind CSS, and Vite.

## Features

- **Interactive 3D Scenes**: Three.js & React Three Fiber canvas with dynamic lighting, particle systems, and interactive shaders.
- **Micro-Animations & Smooth Flow**: GSAP animations and smooth scrolling effects.
- **Projects Showcase**: Highlighting simulation, game development, Unreal Engine, and engineering projects.
- **Responsive & Modern Design**: Dark aesthetic with custom cursor and responsive layouts.

## Tech Stack

- **Framework**: React 19, TypeScript, Vite
- **3D / Graphics**: Three.js, @react-three/fiber, @react-three/drei
- **Styling**: Tailwind CSS
- **Animations**: GSAP, Lucide Icons

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
